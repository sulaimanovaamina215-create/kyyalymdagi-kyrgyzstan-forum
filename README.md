# Кыялымдагы Кыргызстан

Сайт национального молодёжного форума: главная на кыргызском и русском, архив, групповая регистрация делегаций, анонимный опрос и панель организатора.

Стек: Next.js, React, Tailwind CSS. Заявки, анкеты и тексты сайта хранятся в файлах на сервере, где запущен `npm start`. Excel читается и собирается библиотекой ExcelJS.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

- Анкета: http://localhost:3000/opros
- Регистрация делегации: http://localhost:3000/register
- Панель организатора: http://localhost:3000/admin

Скопируйте `.env.example` в `.env.local` и задайте `ADMIN_PASSWORD`. Локальный пример уже лежит в `.env.local` и в git не попадает. Перед публикацией пароль нужно сменить.

Сборка:

```bash
npm run build
npm start
```

## Что править

- Дата форума, телефон, почта и ссылки сетей: `lib/content.ts`
- Пилотные цифры карты: `lib/regions.ts`. Поставьте `pilot: 0`, если на карте должны быть только живые анкеты.
- Программа, новости, организаторы, партнёры, фото и видео: панель `/admin`, раздел «Содержание».
- Логотип: `public/logo.png`
- Адрес в QR: на сайте в блоке опроса впишите опубликованный URL. Либо задайте `NEXT_PUBLIC_SITE_URL`.

## Данные

Заявки делегаций и анонимные анкеты пишутся в `data/submissions.json`. В файле есть имена и контакты, поэтому он не попадает в git. Фото и видео из панели лежат в `data/uploads`. Тексты сайта — в `data/cms.json`.

Запись работает, когда сайт запущен через `npm run dev` или `npm start` на своём сервере. На serverless-хостинге с одноразовой файловой системой нужна база.

Анкета дополнительно уходит в Google Sheets аккаунта Demilgefoundation@gmail.com и присылает письмо со ссылкой на таблицу. Скрипт для таблицы: `scripts/google-survey-webapp.gs`. После развёртывания веб-приложения впишите его URL и тот же секрет в `GOOGLE_SURVEY_WEBHOOK_URL` и `GOOGLE_SURVEY_TOKEN`, затем перезапустите сайт. Пока переменные пустые, ответ остаётся только в `data/submissions.json`. Если таблица недоступна, анкета не считается отправленной и человек видит ошибку.
